Lexeme 1.0

Support

A few essentials for writing and reading Markdown on your Mac.

For more guidance, open Lexeme’s built-in Help and Markdown Reference.

Getting started

Create a new Markdown document or open an existing file using the native macOS document commands. Write in Source or Split mode, then save your document. When saving a new document, choose its name and location.

  • Source: edit Markdown directly with syntax highlighting.
  • Split: edit Markdown alongside a continuously updated rendered preview.
  • Rich: read rendered Markdown. This mode is read-only; switch to Source or Split to edit.

Use Lexeme’s Markdown formatting commands and keyboard shortcuts for common syntax. The built-in Help explains the application’s workflows; the Markdown Reference provides guidance on Markdown formatting.

Supported files

Lexeme opens and saves Markdown documents with .md and .markdown extensions.

Plain-text .txt files can be imported into new Markdown documents. Importing does not modify the original text file. Save the new Markdown document separately.

Troubleshooting

When a document will not open

Confirm that the file is a supported Markdown document and still exists at the location you selected. Check that you can access the file in Finder and have permission to read it. For a file in a cloud-synchronized location, check that it is available locally. Import .txt files into a new Markdown document.

When formatting or the preview looks unexpected

Check the Markdown source in Source or Split mode, including punctuation, indentation, and blank lines. Compare the syntax with Lexeme’s built-in Markdown Reference. If the text’s appearance is unexpected, review the selected theme, fonts, and typography settings.

System requirements

Lexeme 1.0 requires macOS 15.0 or later.
