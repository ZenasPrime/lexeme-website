Lexeme 1.0

Privacy

Privacy policy for Lexeme 1.0, the native Markdown editor for macOS.

Effective date: October 11, 2026.

Accounts and data collection

Lexeme does not require user accounts, collect analytics or tracking data, or include advertising. The application does not transmit document contents or usage data to its developer.

Documents and preferences

Markdown documents are opened and saved using native macOS document workflows. You choose the files you open and the locations where you save them.

User preferences, such as application settings, are stored locally using macOS application preferences.

Third-party storage

If you save files to a third-party or cloud-synchronized location, those files are subject to that service’s handling and privacy policies. Review the policies of the services you use.

Community support

Lexeme’s public support forum on GitHub Discussions is an external service. Posting requires a GitHub account.

Information you voluntarily post there will be handled according to GitHub’s policies. It is not collected through the Lexeme application. Public posts may be visible to others; avoid including private document contents or sensitive information.

Visit Support for help with Lexeme and community support guidance.

Policy scope

This policy describes the behavior of the Lexeme 1.0 macOS application. Apple, macOS, GitHub, and third-party storage providers operate under their own policies. This policy does not describe or make promises about the information those services may collect.
